# 天清节 · 双人同框立绘身高核查

> 核查口径：小红书小工具 WebView（Chrome 61 基线）/ 竖版 390×844。立绘槽 195×624、`baseH=292`；
> 「身高」= **头顶到人物底边的渲染高度**（底对齐渲染下即头顶到槽底），与两人脚底位置无关。
> 数据来源：`.probe_height_audit.js` / `.probe_mem_height.js` 在真实 `index.html` 里逐句量测（改前 = worktree @ `d3b0ea0`，改后 = 当前工作树）。

## 零、结论

1. 全库共 **13 处**双人同框（主线 10 处 / 回忆舞台 3 处），涉及 **9 组配对**，全部以郭荣为基准。
2. 改前 13 处里只有 3 处方向正确（张永德 0.95、殷崇义 0.94、郭威 1.00），其余 **10 处不符**：
   3 处「方向反」（王朴夜宴 1.22、赵匡胤 0.95、玩家 1.06），5 处「被拉平/被压矮」（范质、冯道、符后、王朴辰时、玩家史官），
   1 处「比值对但整体偏小」（张永德绝对尺寸 379px，比隔壁场景小 5%）。
3. 现已全部按用户裁定落地，**13/13 符合**。
4. 顺带修掉一个隐藏 bug：整场第一对同框的缩放停在「对话框未测量时」的旧槽高上，郭荣的 k 少算 9%（1.81 vs 1.987）。

## 一、身高标准（唯一事实源：`js/portraits.js` 的 `STATURE` 表）

| 档位 | 系数 | 角色 |
|---|---|---|
| 基准 | 1.00 | 郭荣（官家） |
| 相若 | 1.00 | 李谷、郭威 |
| 稍高 | 1.04 | 赵匡胤 |
| 稍矮 | 0.95~0.96 | 冯道 0.96、张永德 0.95、李重进 0.95 |
| 矮 | 0.91~0.92 | 范质 0.92、王朴 0.92、王溥 0.92、殷崇义 0.92、符后 0.91 |
| 明显矮 | 0.86 | 玩家（女官 / 史官同值） |
| 特例 | 0.80 / 0.60 | 少年郭荣 / 六岁宗训 |

**落地公式**：两人共用基准 `C`，各自 `k = C × S ÷ (1 − y0)`，`C = min(各方的 几何上限 × hf ÷ S)`。
渲染高度 `= baseH × k × hf = baseH × C × S` ⇒ 高度比**恰好等于 S 之比**，与各图在画布里的留白无关。
`C` 由最吃空间的一方决定，所以谁也不会被裁出槽（`k ≤ cap = min(kTop×0.96, kSide)` 恒成立）。

分档为什么是 4%~14%：390 档下 4% ≈ 17px 头顶差，肉眼可判「谁略高」；再小就与素材误差混在一起。

## 六、留待确认（3 项）

1. **王朴在辰时是跪坐像**：`data.js:239/241` 写 `slot:'e1'`，但王朴只有 `e2`，于是静默回落 `a1`（跪坐）。广德殿站班场合若要用立姿，把 `e1` 改 `e2` 即可（会同时改变这一对的取景高度）。
2. **跪姿像的物理局限**：符后、王朴 a1 这类「跪/坐但把画布撑满」的素材，只能靠整体缩放表达高矮，无法同时做到「头一样大、人矮一截」——真要两全需要重绘（按站姿高度画、人物只占画布 70%）。
3. **张永德那对的整体取景退一档**：他举觞＋佩刀，可见带宽 0.568，`kSide` 是硬约束，所以这一场两人的绝对尺寸比隔壁赵匡胤那场小约 5%。要抹平需给他外溢额度（会同时改变中缝基线 30px），当前按「宁可小一点也不要贴边」处理。
