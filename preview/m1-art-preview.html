天清往事

三段演示：① 广德殿五层视差场景（移动指针/手指滑动看纵深）② 天青瓷器光影特写 ③ 十六片碎片汇聚合瓮 → 平滑过渡庆生画面。低饱和国风 · 非卡通平面 · 全部为 Chrome 61 可用实现（无 3D 引擎、无 WASM）。

① 广德殿 · 五层视差（天空月轮 / 远殿塔影 / 殿身匾额 / 柱列宫灯 / 前景人物香炉）。指针横向移动或手机滑动体验纵深；雾带承担层间融合，消除「剪纸感」。

② 瓷器是全案关键道具：釉面四段纵向渐变 + 左右冷暖双层光（左暖宫灯 / 右冷青环境反光）+ 椭圆高光斑（双层：宽弱光带 + 窄强光芯）+ 细噪滤镜模拟釉面肌理 + 开片纹（金丝级细纹 + 铁线级深纹两组）+ 肩部莲瓣浅刻与两道弦纹 + 暴胎足（胎土色）。侧光晨昏可切换：同一器物换暖/冷主光即得「酉时暗釉档」。

③ 点「瓷片归瓮」：16 片碎瓷自环周依次（40ms 错拍）飞向合瓮点 → 瓷瓶自碎片中显形（透明度+缩放双轨）→ 光晕脉冲 → 白釉闪光转场 → 庆生画面（暖烛低饱和 + 群臣剪影举杯 + 合瓮居案）。整个链路只用 transform/opacity，Chrome 61 GPU 加速可满帧。
