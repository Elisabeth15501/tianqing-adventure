# 天清往事 · 天清节

> 显德五年（958）九月廿四，天清节——后周世宗郭荣的三十八岁生日。
> 你不是他。你是这一日寿宴上的一名宫中礼官：帮他筹备寿宴、拾得御窑天青瓷的碎片、在碎片里看见他的一生，最后与满殿同僚一起，为他过完这个生日。
