## 手札 · 瓷片查看器（2026-11-01）

手札里拾得的瓷片可点开看细节，全部用**2D 序列帧**承担 3D 感，无 WebGL / 无外部请求。

| 交互 | 实现 | 说明 |
|---|---|---|
| 点瓷片 | `.memo-cell` → `openShardViewer(id)` | 按压缩放 + 音效；键盘 Enter/Space 同样可开 |
| 拖动旋转 | `F.spin3d`（lat-long 12yaw×3pitch） | 水平=转视角、垂直=俯仰，松手带惯性；停手 >80ms 不给惯性 |
| 放大 | 双指捏合 / 双击 1×↔2× / 「放大·缩小」按钮 | 范围 1.0–2.5× |
| 切视角 | 「俯视 / 平视 / 仰视」按钮 | 直跳 3 档 pitch，当前档位高亮 |
| 看内壁 | 默认即内壁档；「旋转」按钮切回转台 | 内壁帧是 292–464px 的整张画，才看得清笔触；旋转帧 160px/格 |
| 状态提示 | HUD（视角 n/12 · 俯/平/仰 / 倍率 / 自动旋转中） | 每 200ms 读一次 `mount.__tq()` 只读状态 |
| 返回 | ✕ / 点遮罩 / Esc | 移除弹层，手札滚动位置不变 |
| 翻片 | 标题行 ‹ › | 在「已拾得」里循环翻看，标题右侧显示「第 n / N 枚」 |

**资产分档（都是位图，不是 3D）**

```
assets/shards/shard_NN.webp        12 帧转台 atlas 640×480（4×3，160px/格）
assets/shards/shard_NN_ll.webp     lat-long 1920×480（12yaw×3pitch，160px/格）
assets/shards/shard_NN_inner.webp  内壁静态帧 464×464（整张画，看笔触用）
```

`shard-NN_ll` 缺失 → 自动回退 12 帧转台 → 再回退内壁静态帧 → 最后矢量剪影，永不白屏。

> ⚠ 清晰度上限：`_ll` 每格 160px，旋转档约束在 280px 内显示；**因此进场默认落在「内壁」档**（整张画、可缩放），
> 想换角度点「旋转」。若要把旋转档也做到清晰，需要把 `_ll` 重渲到 320px/格（体积约 ×4）。

### 模块拆分：瓷片查看器 → `js/viewer.js`（2026-11-02）

查看器原先长在 `js/app.js` 里（约 175 行），与手札主流程没有共享状态，却和 1900 行的 app.js 绑在一起
—— 任何一方改手札都可能把对方覆盖掉。现在拆成独立模块：

| 文件 | 职责 |
|---|---|
| `js/viewer.js` | 全部查看器 UI：弹层、翻片、HUD、工具条、内壁/旋转互切。对外只暴露 `TQViewer.open({id, list, shards, sfx})` |
| `js/app.js` | 只剩 15 行薄壳：从存档算出「已拾得清单」喂进去（只有 app.js 知道 save） |
| `index.html` | `<script src="./js/viewer.js">` **放在 app.js 之后** |

**为什么放 app.js 之后**：app.js 一执行就开始画加载页（`buildLoad`），viewer.js 若排在它前面，
解析会挡在首屏之前。放后面 ⇒ 首屏绘制不等它；查看器只在点击时调用，那时早已解析完成。
`app.js` 里调用处有 `if (!window.TQViewer) return;` 兜底，不会白屏。

**加载影响实测**（headless + 本地 http，3 次）：

| 指标 | 拆分前 | 拆分后 |
|---|---|---|
| 同步脚本数 | 11 | 12（+viewer.js 9.6KB） |
| `DOMContentLoaded` | 153–165ms | 165–167ms |
| 单个脚本解析 | — | viewer.js 43–45ms（与 data.js 26ms / app.js 46ms 同量级） |

注：本地 http 每个请求有 30–50ms 的 TCP 开销；**小工具是包内资源，没有网络往返**，
一次本地读 + 解析通常在 1–3ms。结论：拆分对 loading 的影响可忽略，首屏（FCP）不受影响。

**验收页**：`python _qa/make_viewer_check.py 5 _qa_t5.html` —— 从当前 index.html 派生
（不再存静态副本，避免 index.html 加了脚本而副本没跟上，跑起来像坏了）。

**调试入口**：根目录 `_qa_viewer.html`（注入全收集存档 → 自动进手札 → 打开第一枚瓷片的查看器；
assets 相对路径依赖根目录，故不能放进 `_qa/`，仅本地验收用，不进包）。
