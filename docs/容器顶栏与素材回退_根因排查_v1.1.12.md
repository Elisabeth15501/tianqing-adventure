## 1. 问题一：顶栏太高 / 按钮被平台胶囊遮挡

### 根因链

```
getWindowInfo 旧实现只认 Promise（if !pr.then return）
  → 容器/后台预览走回调形态，拿不到结果
  → --tq-top-inset 恒为 0
  → .app 的 padding-top: var(--tq-top-inset) 不下移
  → 平台右上角胶囊（···、○）压住自绘顶栏的「设定 / 手札 / 进度条」
```

### 为什么普通网页正常
网页没有平台胶囊，也没有 `window.xhs.miniTool`，这段逻辑根本不触发；顶栏按原样布局即可。

### 修复
- `app.js` 的 `getWindowInfo` 改为**回调 + Promise 双形态**都接（先传 `{success,fail}`，兼容 Promise 返回）。
- 容器内顶部预留取 `max(实测 top, 44)`；Pages 仍为 0。
- **只由 `.app` 的 padding-top 下移**，不再给 `.topbar` 加 margin——中途试过，与 padding 叠加成双份下移，已回退。

容器桩实测：`--tq-top-inset=47px`、`--tq-set-top=63px`、`.app` padding-top `47px`、`.topbar` margin-top `0px`。

## 2. 问题二：大量场景 / 立绘 / 瓷片未载入（红角标「立绘未载入 · 自检」）

### 红角标触发条件
`portraits.js:883 markMissing()` 只在 `resolve` 返回 `stt==='fail'` 时挂。
`assets.js` 里 `fail` 是**永久缓存**的（`TA.status[key]='fail'`，之后 `resolve` 直接 `cb('fail')`），所以一旦某张图失败，整局都不会再试。

### 根因链

```
旧 imgs 永久缓存全部解码位图
  · 33 张立绘 ≈ 176 MiB
  · 49 张瓷片 ≈ 131 MiB
  · 合计理论峰值 ≈ 300 MiB+（RGBA8 估算）
  → 桌面浏览器无感，小工具 WebView 内存吃紧
  → 新图解码 onerror → finish('fail')
  → status 永久缓存 fail + 矢量回退 + 红角标
```

### 已排除的误判
- 路径大小写 / 文件名：注册表 83 条引用逐条比对，仅可选 `s8_scroll` 缺失。
- WebP 编码 / 尺寸：场景背景与部分立绘是真图，说明 WebP 基本可用；111 张 WebP 全部 ≤2048。
- 外链 / CSP 外部资源：无外部 URL。
- 场景预热：受控（`conc:1` + 延迟 1.2s + 只当前形态），不是内存元凶。

### 次要风险
`paintReal` 旧代码用 `im.src` 的**绝对 URL** 再建 `<img>`；容器 CSP 下绝对 URL 可能被二次拒绝。

### 修复
- `assets.js`：路径常驻（`srcs`）+ 位图 LRU（`imgs`，容器上限 6 / 网页 20）；被淘汰的图再次需要时，`resolve` 按相对路径静默重载。
- `portraits.js`：全部改用 `TQA.src(ak)` 相对路径上图；位图**留在 LRU 不 release**（第一轮在此坑过，见第 5 节）。
- 覆盖路径：单人 `bindSlot`、双人 `bindStage`、回忆容器 `mem-fig` 都走同一条 `show → resolve → paintReal/markMissing`，无第二套独立加载逻辑。

容器桩实测：8 张立绘并发后 LRU=6、`imgs`=6、`srcs` 全在；释放一张后再 `resolve` → `ok` 且位图重载成功；打包产物冒烟 0 异常。

## 3. 为什么"网页正常、容器不行"

两个触发条件在网页都不成立：
- 内存充足 → 位图不超限 → 不会 onerror → 不会 fail；
- 无平台胶囊 + `getWindowInfo` 不触发 → 顶栏按原样布局。

所以这不是"网页那套逻辑错了"，而是两套运行环境的边界差异。

### 第二轮四项根因（已修复）

1. **`releasePortrait` 废掉 LRU**：第一轮加了 LRU，却在 `paintReal` 后 6 处立刻 `release` 刚解码的位图 ⇒ 缓存命中恒 0、每次换人重解码 ⇒ 中后段（女官线全员 / 史官线午时起）内存抖动成批 onerror。已全部移除，位图交 LRU 自淘汰。
2. **fail 永久缓存**：瞬时解码失败把资源钉死整局。改为 `markFail`（记时间戳+次数）→ 冷却 2.5s → 下次 `resolve` 自动重取，上限 3 次；`TQA.retry` 供 onerror 即时解缓存。
3. **破图图标**：`resolve` 报 ok 后新建的 `<img>` 仍可能二次 onerror，旧版无兜底直接露破图+alt文字。现 `pic.onerror` 撤破图、回退矢量、挂角标、`TQA.retry`。
4. **顶栏桥异步注入**：`window.xhs` 延迟注入时 `pull()` 首帧早退，只有 resize 才重试 ⇒ 真机不转屏就永远拿不到 menuButtons ⇒ 胶囊压顶栏。补 6×250ms 幂等重试 `retryPull`。

## 5. 第二轮（containerfix2，同日 00:51）：第一轮为何仍不够

`containerfix.zip` 的字面修复进了包，但真机问题依旧。逐行核对第一轮改动后，定位到**三个此前没看到的次级缺陷**：

### 5.1 `releasePortrait` 把第一轮自己的 LRU 废掉了（素材回退主因）

- 第一轮在 `assets.js` 建了位图 LRU（容器上限 6），却在 `portraits.js` 的 `paintReal` 之后新增了 6 处 `TQA.releasePortrait(ak)`（主舞台 3 + 回忆舞台 3）。
- 后果：每张图**刚解码、刚上图就被从 LRU 删掉** ⇒ 缓存命中率恒为 0 ⇒ 每次换人都重新从磁盘解码。容器内存一抖动就 `onerror`，位图又没缓存可退 ⇒ 回退角标。玩家走到女官线中后段 / 史官线午时后，累积换人次数最多，正好是"从某章节起成批回退"。
- 修复：**移除全部 6 处 releasePortrait**，位图交给 LRU 自己淘汰（容器 6 / 网页 20）。这样同角色二次出场走热路径直达，跨角色由 LRU 控制内存。

### 5.2 `fail` 一旦写入永不重试（把偶发失败放大成永久失败）

- 旧 `resolve`：`status[key]='fail'` 后直接短路 `cb('fail')`，整局再不重取。一次瞬时解码失败 = 该资源整局阵亡。
- 中途尝试过 `im.onerror` 里即时改 `im.src += '?r=1'` 重试，**两个新坑**：
  1. 容器内资产是 zip 内**同源相对路径**，加查询串变成另一个 URL，本地加载器/CSP 可能直接拒绝（治愈反致残）；
  2. 即时重试与冷却重试共用 `_retryN`，即时把次数耗尽 ⇒ 冷却重试永不触发。
- 最终修复：**只保留一条恢复路径**——`markFail` 记时间戳与次数 → 冷却 2.5s → 下次 `resolve` 自动重取，上限 3 次（真 404 放弃，不无限重试）。`assets-check` 与 `TQA.retry(key)` 可手动清缓存立即重取。

### 5.3 `paintReal` 的 `<img>` 无 onerror（破图直接露脸）

- `resolve` 报 `ok`（图曾解码/LRU 命中）后，`paintReal` 新建的 `<img src>` 仍可能因容器内存抖动二次 `onerror`。旧代码没兜底 ⇒ 浏览器破图图标 + alt 文字直接显示给玩家。
- 修复：`pic.onerror` 里撤破图、退回矢量占位、`markMissing(slot,'fail')` 挂可见角标，并调 `TQA.retry(ak)` 清失败缓存，下次剧情切换可再试。

### 5.4 顶栏：`window.xhs` 异步注入 ⇒ 安全区计算一次早退

- `app.js` 的 `pull()` 只在脚本初始化时调一次；若那一刻 `window.xhs.miniTool` 尚未注入就直接 return，之后只有 resize/orientationchange 才重取。真机玩家不转屏 ⇒ 右上角 `menuButtons` 测量从未执行 ⇒ `--tq-topbar-right` 恒 0 ⇒ 胶囊压住「设定/手札」。
- 修复：初始化后追加 **6×250ms 的幂等重试**（拿到桥即停，绝不无限轮询），覆盖容器桥注入窗口。

### 验证（标准环境，非真机）

- 容器桩部署探针（`probe_deploy3.cjs`）：`--tq-top-inset=87px`、`--tq-topbar-right=100px`、`.app` padding 87px、女官立绘 1024px 正常、场景背景在、0 异常。
- 三机制定向探针（`probe_fix_verify.cjs`）：① `resolve` 后 `imgs` 有位图、LRU=5（release 已移除）；② 人为 `fail` + 推旧时间戳后 `resolve` → `ok`（冷却重取生效）；③ 真 `.fig-real` 派发 `error` → 撤图/`has-real` 清除/`fig-miss` 角标出现。
- 包自检：`pack_zip.py` 生成 zip（152 文件、唯一 `index.html`、无 `assets-check`/`tilt-web`/`mini_tool.json`、无重复条目）。
